# How to Use ui-ux-pro-max-skill with VS Code and Roo Code

**Quick Answer**: Use GitHub Copilot Chat with natural language prompts focused on UI/UX improvements.

## For VS Code Users

1. **Install GitHub Copilot** (if not already installed)
   - Install the "GitHub Copilot" and "GitHub Copilot Chat" extensions
   - Sign in with your GitHub account

2. **Open Copilot Chat**
   - Press `Cmd+I` (Mac) or `Ctrl+I` (Windows/Linux)
   - Or click the chat icon in the sidebar

3. **Use UI/UX Focused Prompts**
   ```
   @workspace How can I improve the README to be more user-friendly?
   Can you suggest ways to make the installation instructions clearer?
   Help me organize the documentation for better readability
   ```

## For Roo Code Users

1. **Open Roo Code panel** in VS Code
2. **Start a conversation** about UI/UX improvements
3. **Be specific** about what you want to improve
